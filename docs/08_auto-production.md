# 08 自動作成（機材なし・アニメーション／イラスト・合成音声）

## 方針
- 機材は使わない。映像は **図解・イラスト・キャラクター・画面の自動録画**、声は **合成音声**
- 制作は自動化し、**中身の独自性は人が出す**（現場メモ・台本の承認・完成確認）

## 最大のリスク：「不誠実なコンテンツ」でチャンネルごと収益化できなくなる
- YouTube は、テンプレートでほとんど変化のない量産動画を収益化の対象外としている。判定はチャンネル単位とされる
- 2026年7月の更新で「繰り返しの多いAI生成動画」などが対象として明確化されたと報じられている（日付・分類は報道によって違う。不確か）
- 一方で、**合成音声そのものは自動的に失格にはならない**、AIのラベルを付けても不利にならない、という報道がある（第三者情報）

### 対策（すべて必須）
| 対策 | 具体的に |
|---|---|
| 毎回の現場メモ | 00_memo.md に、自分の経験・失敗・実際の数値を書く。台本はこれを中心に作る |
| 構成の型を回す | 4つの型（図解解説・ケーススタディ・比較・Q&A）を順番に使う。フック型も連続させない |
| 動画ごとの専用の映像 | その動画のための図解・画面録画を必ず入れる。素材サイトの映像を並べるだけにしない |
| 固定のキャラクター | 案内役のキャラクターを1人決め、毎回同じ見た目・同じ声にする（チャンネルの顔になる） |
| 実在の人物の声を使わない | 声のクローンは使わない |
| 量産しない | 長尺 週1本＋縦型 週3本 |
| 人の確認 | 台本の承認と完成動画の通し確認を必ず行う |

## 合成音声
| 候補 | 特徴 | 注意 |
|---|---|---|
| **VOICEVOX（推奨）** | 無料・ローカルで動く・API で自動化しやすい | 商用利用はキャラクターごとの規約に従う。多くは「VOICEVOX:キャラクター名」のクレジット表記が必要（要確認） |
| 有料の音声合成サービス | 声が自然 | 月額費用。規約の確認が必要 |
- 専門用語の読み方は辞書に登録する（例：絶縁抵抗、ELB、VCT、GX Works2）。辞書は scripts/voice_dict.csv で管理する（作成予定）

## 映像の作り方
| 種類 | 作り方 | 例 |
|---|---|---|
| 図解・スライド | HTML のテンプレートに文字と図を流し込み、画像にする | 判定基準の表、手順の流れ図 |
| 単線結線図・回路図 | 個人で作り直した作図ツールか SVG で描く | 高圧受電設備の構成 |
| キャラクター | 決めたキャラクターの表情を数枚用意し、話している間だけ口や体を動かす | 案内役 |
| 画面の自動録画 | Playwright でブラウザ操作を自動録画する | AI に報告書を書かせる様子、自作アプリのデモ |
| 動き | 拡大・移動・強調の枠・文字の出現を ffmpeg で付ける | 大事な数値を強調 |
- イラストを画像生成AIで作る場合は、そのサービスの規約（商用利用・権利）を確認する

## 処理の流れ（/render）
1. 03_scenes.json（シーンごとのナレーションと映像の指定）を読む
2. VOICEVOX でシーンごとの音声を作り、長さを測る
3. シーンごとの映像（図解・キャラクター・画面録画）を作る
4. 音声の長さに合わせて映像をつなぎ、字幕（台本の文字から作るので誤変換なし）と BGM を付ける
5. 横（16:9）の長尺と、縦（9:16）の縦型を同じシーン表から書き出す
6. 完成動画を人が通しで確認する

## 開示
- アニメーション・イラストは現実と誤認されにくいため、YouTube の「改変または合成されたコンテンツ」の開示は不要な場合が多い（判断は動画ごと。不確か）
- TikTok は AI で作った現実的なコンテンツにラベルを求めている。迷ったらラベルを付ける
