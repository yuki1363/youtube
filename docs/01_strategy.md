# 01 全体設計

## ゴール
- 第1目標：**開設から12か月以内に月1万円を広告収益で達成**（アフィリエイトは補助）
- 第2目標：24か月目までに月10万円（広告＋アフィリエイト＋BOOTH＋Udemy＋企業案件）[推測]
- 90日のゴールは「運用の型が回っている状態」

## 広告で月1万円に必要な数字 [推測]
| 長尺のRPM | 月1万円に必要な長尺の月間再生 |
|---|---|
| 300円 | 約3.3万回 |
| 500円（仮置き）[要実測] | 約2万回 |
| 900円 | 約1.1万回 |
- 総再生8,000時間は、平均視聴4分なら年12万回の再生。その時点で月1〜2万回のペースになっているため、第1目標は広告だけで届く水準

## 収益化条件（2026年11月時点。公式ヘルプで要再確認）
- 現行：登録者1,000人＋総再生時間4,000時間/12か月、またはShorts 1,000万回/90日
- 2027年2月1日以降の新規申請：8,000時間/365日、またはShorts 2,000万回/90日（第三者サイト報道。要確認）→ **本計画はこちらを前提にする**
- Shortsの再生は長尺の総再生時間にカウントされない
- 「不誠実なコンテンツ」ポリシー（2025年7月〜）：テンプレ台本＋合成音声＋素材映像の大量投稿は審査で落ちやすい。判定はチャンネル単位とされる
- 2026年10月：他人の動画をほぼそのまま再投稿した Shorts の表示を減らす変更が報じられている

## 設計方針
- 制作は自動化する（アニメーション・イラスト・合成音声）。ただし**中身の独自性は人が出す**：毎回の現場メモ、台本の承認、完成動画の確認
- AIの量産チャンネルと見なされないことが最重要（判定はチャンネル単位）。対策は docs/08_auto-production.md
- 検索から見つかり、長く再生され続ける長尺動画を積み上げる（総再生時間が最優先）
- 縦型（Shorts・TikTok）は長尺への入口
