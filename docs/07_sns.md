# 07 SNS運用（TikTok・YouTube Shorts）

## 目的
縦型動画は **YouTube 長尺への入口**。TikTok 自体の収益化は当面狙わない。
- TikTok の収益化（Creator Rewards Program）は、個人アカウント・フォロワー1万人以上・直近30日の視聴10万回以上・1分以上の動画が条件と報じられている（第三者情報。公式で要確認）

## 制作ルール
| ルール | 理由 |
|---|---|
| scripts/shorts.sh で書き出した元ファイルを、YouTube Shorts と TikTok の両方に投稿する | 追加の制作時間をほぼゼロにする |
| TikTok からダウンロードしたロゴ入り動画を YouTube に上げない | 転載に見え不利になる可能性（不確か）。YouTube は2026年10月に再投稿動画の表示を減らす変更をしたと報じられている |
| 長さは30〜60秒。TikTok の収益化を狙う段階で1分以上の版を作る | TikTok の収益化対象は1分以上と報じられている |
| 長尺の「結論だけ」を見せ、手順の続きは長尺へ | 長尺の総再生時間を増やす |
| 最後の2秒と固定コメントで「続きは YouTube で『チャンネル名』と検索」 | TikTok は外部リンクを置ける場所が少ない |
| チャンネル名・ユーザー名を YouTube と TikTok で揃える | 検索で見つけてもらう |
| TikTok の説明文は YouTube と別に作る（ハッシュタグ3〜5個） | 文化が違う。/shorts で作り分ける |

## アカウント設定（TikTok）
| 項目 | 推奨 | 理由 |
|---|---|---|
| アカウント種別 | 個人アカウント | 将来の収益化の条件。ビジネスアカウントはフォロワー数に関係なくリンクを貼れるとされるが収益化の対象外（第三者情報） |
| プロフィールのリンク | フォロワー1,000人までは URL を文字で書き、チャンネル名での検索を案内 | 個人アカウントのリンクはフォロワー1,000人が必要とされる（第三者情報） |
| 「他の人におすすめ」（連絡先・友達への表示） | オフ | 職場の人に見つかるのを防ぐ |
| 連絡先の同期 | オフ | 同上 |
| 位置情報 | オフ | 工場の場所の特定を防ぐ |

## 投稿ペース（週）
| 種類 | 本数 | 投稿 |
|---|---|---|
| 長尺（YouTube） | 1本 | ユーザー |
| 縦型（同じファイル） | 3本 | ユーザーが YouTube Shorts と TikTok の両方に投稿 |

## 効果の測り方
- YouTube Studio：「トラフィックソース → 外部」と「YouTube 検索の検索語（チャンネル名）」
- TikTok：analytics/tiktok.csv に週1回記録（視聴数・プロフィール表示数・フォロワー増）
- TikTok から YouTube に移った視聴は正確に計測しきれない可能性がある（不確か）。チャンネル名の検索回数を代わりの指標にする
- 3か月目に TikTok からの流入がほぼなければ投稿本数を減らし、その時間を長尺に回す
