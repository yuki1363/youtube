# 03 動画の型（Shorts・30〜50秒）

| 工程 | ルール |
|---|---|
| 企画 | 「誰でも見たことがある」「理由を知らない」「出典で確かめられる」の3つが揃ったものだけ採用 |
| フック | 3型を順番に使う：①結果を先に言う ②疑問を突きつける ③意外な数字（出典つき） |
| 冒頭1秒 | 映像と文字で疑問か答えを見せる。あいさつ・自己紹介はしない |
| 構成 | 疑問 → 答えの一言 → 仕組み（図解2〜3枚） → 「だから〇〇なんです」 → 次の動画への一言 |
| 図解 | 1本に2〜4枚。2〜3秒ごとに画面を変える。文字は1枚10字以内 |
| 台本 | 話し言葉。1分あたり約300字なので、45秒で約220字 |
| 字幕 | 全部の発話に入れる。画面の中央より下、指で隠れない位置 |
| タイトル | 疑問形か「〇〇の理由」。30字以内（推測） |
| 説明欄 | 出典を必ず書く |
| ループ | 最後の一言が最初の疑問につながると、もう一度見られやすい（推測） |

## 1本の制作時間の目標
人の作業30分以内 [要実測]。最初の3本で計り、plan/90days.md の値を直す
