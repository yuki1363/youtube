# 04 指標と改善

## 8指標の読み方
「表示される → クリックされる → 見続けられる → また来る」の流れで、止まっている箇所だけ直す。
比較対象は業界平均ではなく、自分の過去動画の中央値。

| 指標 | 意味 | 判断 |
|---|---|---|
| インプレッション | 表示回数 | 少ない → テーマか検索語のズレ |
| CTR | クリック率 | 流入元ごとに自分の過去と比較 |
| 視聴時間 | 収益化条件そのもの | 1本あたりの合計 |
| 維持率 | 離脱位置 | 冒頭30秒の残存率と急落箇所 |
| リピーター | 再訪者 | 増加 = シリーズ化が効いている |
| 関連動画 | 他動画の横からの流入 | 自分の動画同士の回遊 |
| 検索流入 | 検索からの流入 | 立ち上げ期の主役 |
| 推薦 | ホームからの流入 | 満足度が溜まると後から伸びる |

## 広告収益の追加指標（収益化後）
| 指標 | 意味 | 判断 |
|---|---|---|
| 総再生時間（365日） | 収益化条件（8,000時間） | 月ごとの増え方で到達時期を予測 |
| RPM | 1,000再生あたりの収益 | 柱ごとに比べ、高い柱を増やす |
| ミッドロールの有無 | 途中広告の入った動画の割合 | 8分以上の長尺で設定 |

## 修正条件
| こうなったら | こう直す |
|---|---|
| 公開48時間のインプレッションが中央値の半分以下 | タイトル・説明文の検索語を見直す |
| CTRが中央値より明確に低い | 「テストと比較」で検証 |
| 冒頭30秒の残存率が低い | フック型を変え、タイトルとのズレをなくす |
| 同じ柱が3本連続で伸びない | その柱を減らす |
| 週5時間超過が2週続く | Shortsを減らす（長尺は守る） |
| 視聴は多いが登録が少ない | 終了画面とシリーズ導線を直す |
| 60日時点で検索流入がほぼない | 検索語を選び直す |
| 6か月目で総再生2,000時間未満 | 柱D・F（基礎・資格）の比率を上げる／可能なら長尺を週2本 |
| 9か月目で総再生4,500時間未満 | 第1目標の時期を15か月目に延ばすか、投稿を増やすかを決める |
| 3か月目で TikTok からの流入がほぼない | 縦型の本数を減らし長尺に時間を回す |

## テストと比較（YouTube Studio）
- タイトル・サムネイル・組み合わせを最大3案。勝敗は表示あたりの総再生時間で決まる
- 「高度な機能」の有効化が必要。PCのみ。Shortsは対象外
- 1回に変える要素は1つ。結果は analytics/ab-tests.csv に記録
