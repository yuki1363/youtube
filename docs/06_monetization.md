# 06 収益化

## 導入順
| 段階 | 目安 | 導入するもの |
|---|---|---|
| 0 | 開設〜500人 | アフィリエイト、無料プロンプト配布＋ニュースレター、BOOTHテンプレ。Udemy構成案 |
| 1 | 500人〜 | Udemy講座公開（クーポンで誘導）、ファン支援機能 |
| 2 | 収益化条件達成 | 広告、Shorts広告 |
| 3 | 数千人〜（推測） | スポンサー |
| 4 | 余力がある場合のみ | メンバーシップ、コミュニティ |

## 導線
動画 → 概要欄の無料プロンプト（メール登録） → ニュースレター → BOOTH → Udemy

## 月1万円の組み立て例（推測）
Udemy 5,000〜8,000円 ＋ アフィリエイト 1,000〜2,000円 ＋ BOOTH 1,000〜3,000円

## 法務・リスク
- ステマ規制：広告は「PR」表示＋YouTubeの有料プロモーション設定
- 勤務先の取引先・競合メーカーのスポンサーは利益相反に注意。副業規定を事前確認
- 給与以外の所得が年20万円超なら確定申告（詳細は税務署・税理士へ）
- 講座に勤務先の事例・社内資料を使わない
- 対象外：コンサル、受託開発（既に決定済み）
