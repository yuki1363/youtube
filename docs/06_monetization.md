# 06 収益化

## 導入順（第1目標は広告で月1万円）
| 段階 | 目安 | 導入するもの |
|---|---|---|
| 0 | 開設〜 | アフィリエイト（概要欄に置くだけ。工具・測定器・書籍・AIツール・資格講座） |
| 1 | 登録者1,000人＋総再生8,000時間（9〜12か月目） | **YPP申請 → 広告・Shorts広告**（第1目標：月1万円） |
| 2 | 13か月目〜 | BOOTH（テンプレート・プロンプト集・個人で作り直したツール） |
| 3 | 16か月目ごろ | Udemy講座（AIで保全業務を効率化）、ニュースレター |
| 4 | 登録者3,000人前後〜（推測） | 企業案件（製造業向けIT・測定器メーカー） |
| 5 | 余力がある場合のみ | メンバーシップ、コミュニティ |

## 第2目標（月10万円）の内訳例 [推測]
| 収益源 | 24か月目の目標 |
|---|---|
| 広告 | 3〜5万円（長尺 月6〜10万回 × RPM 500円） |
| アフィリエイト | 1〜2万円 |
| Udemy | 2〜3万円 |
| BOOTH | 0.5〜1万円 |
| 企業案件 | 0〜3万円 |
| 合計 | 約7〜14万円 |

## 導線
縦型（TikTok・Shorts）→ 長尺 → 同じシリーズの次の長尺 → 概要欄（アフィリエイト）→ 第2目標で BOOTH・Udemy

## 法務・リスク
- ステマ規制：広告は「PR」表示＋YouTubeの有料プロモーション設定。TikTok は「ブランドコンテンツ」設定
- 勤務先の取引先・競合メーカーのスポンサーは利益相反に注意。副業規定を事前確認
- 勤務先の業務で作ったアプリ・資料は販売しない。個人で作り直したものだけ販売する
- 給与以外の所得が年20万円超なら確定申告（詳細は税務署・税理士へ）
- 講座に勤務先の事例・社内資料を使わない
- 対象外：コンサル、受託開発（既に決定済み）
