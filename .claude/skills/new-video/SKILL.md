# 新しい動画を始める（SNS収集部門 → 情報調達部門 → 法務 → 統括）

1. docs/01_strategy.md、docs/02_departments.md、docs/03_format.md、docs/video-ideas.md、plan/ideas-inbox.md を読む
2. SNS収集部門：Web検索で「なぜ？」系の話題を探し、動画案と受け箱から候補を3つ出す。ユーザーが選ぶ
   - X・TikTokに届かない場合は、ユーザーにURLか画面写真を求める
3. `bash scripts/new_video.sh <通し番号> <英小文字の短い名前>` を実行する
4. 情報調達部門：01_research.md の出典表を埋める。公的機関・メーカー・特許を優先し、個人ブログだけを根拠にしない
5. 法務・権利部門：危険な分解・勤務先特定・他人の素材の懸念を書く
6. 統括：判定案（採用/不採用）を示して、ユーザーの確認で止まる
