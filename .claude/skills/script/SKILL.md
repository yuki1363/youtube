# 台本を作る（作成部門 → 内容精度部門 → 統括）

前提：01_research.md が「採用」になっていること。

1. 読む：docs/03_format.md、templates/script.md、対象フォルダの 01_research.md
2. analytics/log.csv で直前の動画の hook_type を確認し、**違う型**を選ぶ
3. 作成部門：02_script.md の6項目を埋める。約220字・話し言葉。図解の案は2〜4枚
4. 内容精度部門：台本の文ごとに ○／△／× を判定し、出典URLを書く。×は削除、△は言い換える
5. セルフレビュー：冒頭1秒で疑問か答えが出ているか／出典のない断定がないか／禁止事項に触れていないか
6. `status: draft` のまま止め、ユーザーに確認を依頼する。承認後にユーザーが approved に変える
7. 承認後、図解画像生成部門が 07_figures/ に図を作る（scripts/figures/ のコードを使う）
