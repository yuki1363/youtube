# サムネイル3案

1. 02_script.md のサムネイル案から、大きい文字（10字以内）と小さい文字を決める
2. ビフォー/アフター画像をユーザーに確認する（04_raw から切り出す場合は ffmpeg で静止画を作る）
3. `python3 scripts/thumbnail.py --text ... --sub ... [--left ...] [--right ...] --out <動画フォルダ>/06_thumb` を実行
4. 3案は配色だけが違う。採用案と「テストと比較」にかける案はユーザーが選ぶ
