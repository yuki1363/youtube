# Shorts 3本

1. 05_edit の .srt と 02_script.md から、次の3区間（各60秒以内）を選んで提示する
   - フックの場面／失敗シーン／まとめ3ポイント
2. ユーザーの確認後、`scripts/shorts.sh <動画> <srt> <開始> <終了> <動画フォルダ>/09_shorts/shortN.mp4` を3回実行
3. 各Shortsのタイトル・説明文を、YouTube／TikTok／Reels用に作り分けて 07_meta.json の shorts に書く
4. 関連動画（長尺本編）へのリンク設定をユーザーに案内する
