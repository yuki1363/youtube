# 週次レビュー

入力：YouTube Studioから書き出したCSV（または数値）、TikTok の数値（視聴数・プロフィール表示数・フォロワー増）、今週の工程ごとの作業時間。

1. 数値を analytics/log.csv と analytics/tiktok.csv に反映する
2. 読む：docs/04_algorithm.md、plan/90days.md
3. 部門ごとに検討し、最後にリーダーとしてまとめる
   - 分析：8指標を自分の中央値と比較して要約。総再生時間（365日）の増え方から8,000時間の到達月を予測
   - 改善：docs/04_algorithm.md の修正条件に当てはまる項目と、次の一手
   - 制作：来週のテーマを docs/video-ideas.md から選び、理由を付ける
   - SNS運用：TikTok の数値と、YouTube の外部流入・チャンネル名検索の変化
   - 収益化：アフィリエイトのクリック、収益化後は RPM（柱ごと）
   - 運用：作業時間が週5時間を超えていれば削る作業を提案
   - 計画：plan/90days.md の修正要否。完了した週にチェックを付ける
4. 推測と実測を分けて書く
5. 30日・60日・90日の節目では、マイルストーンの推測値を実績で置き換える提案をする
