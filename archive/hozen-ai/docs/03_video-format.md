# 03 動画の型

## 9工程のルール
| 工程 | ルール |
|---|---|
| 企画 | 「現場の悩み」「検索される言葉」「AIでの解決策」の3つが揃ったものだけ採用 |
| フック | 3型を順番に使う：①結果を先に見せる ②失敗を先に見せる ③数字で比べる |
| タイトル | 検索語を前半に。数字か具体的な成果を入れる。30字前後（推測） |
| サムネイル | 要素3つまで。文字10字以内。「手作業→AI」のビフォーアフター |
| 冒頭30秒 | 0〜5秒で結果、5〜20秒で共感、20〜30秒で得られることを約束 |
| 構成 | 問題 → なぜ起きるか → 実演 → 失敗例 → 注意点 → まとめ |
| 離脱防止 | 冒頭で後半の見どころを予告。60〜90秒ごとに画面を変える。チャプター必須 |
| CTA | 途中で関連動画、最後に概要欄の特典。冒頭で登録のお願いはしない |
| 台本 | 話し言葉。1分あたり約300字 |
