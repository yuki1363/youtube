# 90日計画（2026-11-23 開始）

時間配分は docs/01_strategy.md（週約4時間・推測値）

## 毎日の習慣（平日10分）
- コメント返信
- 公開48時間以内のShortsの視聴回数と「スワイプされずに見た率」を確認
- 気になった「なぜ？」を1行メモ（plan/ideas-inbox.md）

## 13週間
- [ ] 第1週：副業規定の確認／チャンネル開設（名前・アイコン・説明）／setup.sh／001を公開
- [ ] 第2週：Shorts 3本／工程ごとの時間を実測
- [ ] 第3週：Shorts 3本／図解のテンプレ（色・フォント）を固定
- [ ] 第4週：Shorts 3本／30日レビュー（10本の伸びたテーマの共通点）
- [ ] 第5〜8週：Shorts 週3本／伸びたテーマを増やし、伸びないテーマを減らす
- [ ] 第8週：60日レビュー／長尺（まとめ動画）を作るか判断
- [ ] 第9〜12週：Shorts 週3本（長尺を始めるなら Shorts 2本＋長尺1本）
- [ ] 第13週：90日レビュー／次の90日計画

## マイルストーン（推測値。30日レビューで実績に置き換える）
| 時点 | 目安 |
|---|---|
| 30日 | Shorts 10本。1本の人の作業が45分以内 |
| 60日 | Shorts 22本。伸びるテーマの型が2つ見つかる |
| 90日 | Shorts 36本。登録者数・再生数の目標は30日レビューで実績から決める |
