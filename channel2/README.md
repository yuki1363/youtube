# 第2チャンネル（一般向け・再生数狙い）　ジャンル：A 決定（2026-11-22）／時間配分は確認待ち

本チャンネル（保全×AI）とは別。CLAUDE.md の作業ルール・禁止事項・人の関門2つはこちらにも適用する。

## 部門別の検討
### 戦略：ジャンル候補
| 候補 | 伸びやすさ | 競合 | 自分の強み | 収益化リスク | 判定 |
|---|---|---|---|---|---|
| A. 身近なモノの仕組み・工場の裏側（「〇〇はどうやって動いてる？」） | 高（推測。誰でも気になる） | 中 | **高**（設備・電気・機械の知識がそのまま使える） | 低 | **推奨** |
| B. 「本当か試してみた」検証系 | 高（検証系が伸びているという記事あり） | 高 | 中 | 低 | 次点（実験の手間が大きい） |
| C. AI生成キャラ・AIエンタメ | 当たれば大きい | **非常に高** | 低 | **高**（量産型AIコンテンツは収益化不可になりうる） | 不採用 |
| D. ニュース・ネタのまとめ | 中 | 非常に高 | 低 | 高（再利用コンテンツ扱いの恐れ） | 不採用 |

- 根拠：「AI」という語はタイトルでの拡散力が平均以下という分析記事がある（tubesaku。本文は取得できず、検索結果の要約のみ＝不確か）
- 根拠：「検証」「密着」など体験型が伸びているという個人ブログの指摘（確度は中程度）

### 制作
- 形式：Shorts中心（30〜50秒）。顔出しなし。図解＋自分の声（またはVOICEVOX。規約とクレジットは要確認）
- 1本あたり人の作業：30分以内が目標 [要実測]
- 実物の撮影が必要なときも、社内・工場の中は撮らない（自宅や市販品で撮る）

### 分析
- 指標は本チャンネルと同じ（docs/04_algorithm.md）。Shortsは「スワイプされずに見た率」と平均視聴率を重視
- 10本出した時点で、伸びたテーマの共通点を見て柱を絞る

### 法務・安全
- 勤務先・設備が特定できる情報は禁止（本チャンネルと同じ）
- 副業規定の確認は本チャンネルの第1週タスクと共通
- 他人の動画・画像は使わない。図は自作する

## 時間配分の案（要確認：週5時間の前提に関わる）
- 本チャンネルのShorts 週2〜3本 → 週1本に減らし、空いた時間で第2チャンネルのShortsを週3本作る
- 合計で週5時間以内を保つ

## リーダー判断
A「身近なモノの仕組み」を推奨。理由：一般向けでも再生が取れるテーマで、ユーザーの知識が強みになり、AI量産チャンネルと差がつく。
